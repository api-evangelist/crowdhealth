# CrowdHealth

> CrowdHealth is an Austin, Texas company offering community-powered health care crowdfunding as an alternative to traditional health insurance. Members pay a $60 monthly advocacy fee and commit a monthly contribution amount ($500–$15,000) that is used to fund other members' eligible medical bills peer-to-peer, without premiums, networks, or claim denials.

> Generated by API Evangelist from the CrowdHealth public website on 2026-08-12. CrowdHealth does not publish an llms.txt of its own (https://www.joincrowdhealth.com/llms.txt returns 404).

## API surface

CrowdHealth publishes **no public API**. There is no developer portal, no OpenAPI or AsyncAPI
specification, no SDK, no webhook catalog, no MCP server and no A2A agent card. The only API
observed is a private Apollo GraphQL endpoint at `https://api.joincrowdhealth.com/graphql` that
serves CrowdHealth's own web and mobile applications; GraphQL introspection is explicitly disabled
in production (`INTROSPECTION_DISABLED`) and the endpoint enforces Apollo CSRF prevention. It is not
offered to third-party developers.
